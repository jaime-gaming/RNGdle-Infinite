# QA — v0.5.2 fix3: account-safe resets, digit box, Special & Limiteds, Black Friday 2026

Date: 2026-11-07 · Branch: `arena/be488ed9-rngdle-infinite` · Internal label:
`RNGdle-Infinitev0.5.2fix3` (no `bf` suffix, per user request).

## Scope

1. **Digit box.** The cream "fitting" box and dotted underline around digits
   that are still scrambling were removed; the box that holds the seven digits
   stays. Scrambling digits now read as muted ink
   (`--scramble-ink`, a mix of the equipped aura colour and the box ink);
   revealed digits keep the older high-contrast look. Files:
   `src/number-box.css`, `src/roll.css`, `src/draw-stage.css`.
2. **Prestige never wipes account data.** `startNewCycle` keeps `goalId`
   unconditionally and no longer clears `loadouts`; owned/equipped auras,
   settings, bookmarks and history were already preserved. Fresh Start keeps
   its documented history wipe. `tests/account-aura-fixes.spec.js` updated.
3. **"Special & Limiteds".** The retired-cosmetics collection is renamed
   everywhere (shop hub, shelf heading, breadcrumb, wardrobe filter, card
   source line) and the hub shows one banner per event group
   (`EVENT_AURA_FAMILIES`: RNGween 2026 and, on its day, Black Friday 2026).
4. **Black Friday 2026** (`src/black-friday.js` + UI files). One UTC day,
   Friday 27 November 2026:
   - every shop product discounted 20–50% per product (stable FNV-1a hash),
     companions included; prices floor to whole hundreds so the real discount
     never undercuts the tag;
   - one sale stamp per purchase (`progress.blackFriday.stamps`, cap 99);
   - 25 stamps unlock the limited skin `blackout-2026` ("Blackout 2026",
     matte-black NumberBox art), kept through every reset;
   - the RNGween looks a save missed return to the counter at 10,000,000 EP
     each for the day (`resalePrice`, receipt in `rngweenLimited`);
   - UI: `SALE SALE SALE` ticker above the header, black "Event" flag at the
     top of the shop opening an explainer dialog, stamp card on the hub,
     Ultra-Black and Red Sale themes in the appearance menu, sale favicon /
     touch icon / manifest — all only while the day is on;
   - history gains parse-only-friendly `sale-reward` rows (no EP, never
     counted as spending) and the activity feed renders them.
5. **Sandbox date.** Shipped code never fakes today's date; dev builds honour
   `VITE_BLACK_FRIDAY_PREVIEW_AT` (UTC epoch ms) to shift the sale clock. The
   sandbox dev server runs with
   `VITE_BLACK_FRIDAY_PREVIEW_AT=1795780800000` (2026-11-27 12:00 UTC).

## Verified in this sandbox

- Node-level reducer/price checks: discount spread across 61 products inside
  20–50%; sale-day prices (quickwind-1 30,000 → 21,000); counter price exactly
  10,000,000; stamp accrual, skin unlock at 25, resale purchase, junk-record
  repair, JSON round-trip of `blackFriday` and `sale-reward` rows.
- `src/cloud-save.js`: `investedWealth` values counter cosmetics at 10M,
  `saveHasProgress` and `compareSaveRichness` consider stamps/skin —
  `npm run verify:cloud` passes.
- `npm run audit:economy` passes with the sale-day price table.
- `npm run build` passes; `npx prettier --check` clean on touched files.
- Sale PNG icons generated by `tools/make-sale-icons.mjs` (no ImageMagick SVG
  delegate in this sandbox) and visually inspected at 512px.
